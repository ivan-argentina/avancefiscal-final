# Avance Fiscal

Sistema de gestión comercial y facturación electrónica desarrollado para pequeñas y medianas empresas de Argentina.

Avance Fiscal integra administración de clientes, proveedores, compras, ventas, stock, cuentas corrientes y facturación electrónica ARCA (ex AFIP) en una única plataforma web.

---

# Características

- Facturación electrónica ARCA
- Notas de Crédito
- Presupuestos
- Remitos
- Gestión de Clientes
- Gestión de Proveedores
- Gestión de Artículos
- Control de Stock
- Compras
- Cuentas Corrientes
- Dashboard de indicadores
- Envío de comprobantes por Email

- Multiempresa
- Gestión de usuarios y permisos

# Arquitectura

La aplicación está dividida en tres componentes principales:

- Frontend desarrollado en React.
- Backend desarrollado con Node.js y Express.
- Base de datos PostgreSQL administrada por Supabase.

Toda la autenticación se realiza mediante Supabase Auth.
